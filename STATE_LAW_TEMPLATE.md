# State Leave Law Template\n\nThis template serves as a guide for adding new state leave of absence laws to the database.\n\n## How to Use This Template\n\n1. Copy this file to `states/[STATE-CODE]/laws.json`\n2. Replace `[STATE-CODE]` with the official 2-letter state abbreviation (e.g., WA, MA, IL)\n3. Fill in the jurisdiction and jurisdiction_name fields\n4. Add all applicable leave laws for that state\n5. Verify all information against official government sources\n6. Validate JSON formatting before submitting\n\n## Template Structure\n\n```json\n{\n  \"jurisdiction\": \"US-[STATE-CODE]\",\n  \"jurisdiction_name\": \"[Full State Name]\",\n  \"laws\": [\n    {\n      \"id\": \"[state_code]_[law_id]\",\n      \"name\": \"[Full Name of Law]\",\n      \"abbreviation\": \"[ABBR]\",\n      \"statute_code\": \"[Legal Citation]\",\n      \"effective_date\": \"YYYY-MM-DD\",\n      \"description\": \"[Brief description of what the law provides]\",\n      \"leave_types\": [\n        {\n          \"type\": \"[one of: sick, parental, bereavement, military, jury_duty, voting, domestic_violence, adoption, sabbatical, medical, disability, other]\",\n          \"duration\": {\n            \"value\": [number],\n            \"unit\": \"[days/weeks/months/years]\",\n            \"notes\": \"[Additional context about duration]\"\n          },\n          \"paid\": [true/false/null if not specified],\n          \"eligibility\": {\n            \"min_employment_duration\": \"[e.g., '90 days', '12 months', '0']\",\n            \"min_employer_size\": [number or null if no requirement],\n            \"other_requirements\": [\n              \"[Requirement 1]\",\n              \"[Requirement 2]\"\n            ]\n          },\n          \"notice_requirement\": \"[e.g., '30 days advance notice', 'As soon as practicable']\",\n          \"job_protection\": [true/false]\n        }\n      ],\n      \"official_url\": \"[Link to official government source]\",\n      \"last_updated\": \"2024-01-01T00:00:00Z\",\n      \"notes\": \"[Additional important details or clarifications]\"\n    }\n  ]\n}\n```\n\n## Key Considerations\n\n### Leave Types\nChoose from these standard categories:\n- **sick** - Employee's own illness, medical appointments, or family care\n- **parental** - Maternity, paternity, or adoption leave\n- **bereavement** - Death of family member\n- **military** - Military service or military family leave\n- **jury_duty** - Jury service\n- **voting** - Time off to vote\n- **domestic_violence** - For survivors of domestic violence/sexual assault\n- **adoption** - Adoption-related leave\n- **sabbatical** - Extended unpaid leave (if applicable)\n- **medical** - Medical procedures or conditions\n- **disability** - Disability-related leave\n- **other** - Anything not fitting above categories\n\n### Paid vs. Unpaid\n- `true` = Paid leave\n- `false` = Unpaid leave\n- `null` = Varies by situation or not specified\n\n### Important Notes\n- All information MUST come from official government sources (.gov websites)\n- Always include the statute code and official URL\n- Note any interactions with federal law (FMLA, etc.)\n- Document any employer size thresholds\n- Include all eligibility requirements\n- Update the `last_updated` timestamp when making changes\n\n## Examples\n\n### Single Paid Leave Type\n```json\n{\n  \"id\": \"state_paid_sick_leave\",\n  \"name\": \"State
